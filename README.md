An interactive educational simulation designed to visualize key concepts in recombinant DNA technology — from restriction enzyme cutting and sticky-end formation to DNA ligation.

## ✨ Features

- 🧬 **Restriction Enzyme Simulation** — Identify restriction sites and simulate DNA cleavage.
- ✂️ **Sticky-End Visualization** — See how staggered cuts create complementary overhangs.
- 🔗 **DNA Ligation** — Match compatible sticky ends and form recombinant DNA.
- 🔬 **Step-by-Step Learning** — Understand the process by interacting with the DNA.
- 🌙 **Dark Interface** — Clean, focused visual design for learning.

> **Learn by doing.**
